## Description
RustChain’s public Proof-of-Antiquity documentation describes a hardware fingerprint gate before antiquity weighting is applied. Its whitepaper documents six required fingerprint checks and shows failed fingerprints receiving zero reward weight in the published example algorithm.

This short explains that design without claiming the checks are impossible to bypass. Verify the current implementation and documentation directly in the public repository:
